# ControlLab 0.2.0 发布说明草稿

ControlLab 将手动体验、Python 编程、传统反馈控制和强化学习放在一个倒立摆课堂中。本版提供 Windows 桌面程序、命令行和可选的独立 CPU 训练环境。

- 32 课引导与练习模板，保存学习进度、代码和实验记录；外部实验及解释题由学生或教师确认。
- P、PD、PI/PID、回中反馈、积分抗饱和和低通滤波；查看控制分量及实际限幅。
- 冻结的 `balance-v1` 非零初态评价，完整保留失败与控制错误；练习、验证和保留测试分开，报告比较检查实验条件。
- 学生可写 `control(state, dt)` 和可选 `reset()`，继续兼容旧 `Controller` 类。
- 独立 CPU PPO 训练、停止并保存、继续训练、模型验证和回放；基础安装包不捆绑 PyTorch。
- TITA 外部仿真环境配置和检查入口；不包含 TITA 实机控制。
- 用户主动检查 GitHub Releases，分步下载、SHA256 校验和安装器交接，学习数据与安装目录分开。

便携版需要解压并保留整个文件夹。安装版按当前用户安装。强化学习首次配置需要 Python 3.11–3.13 和网络，在程序目录运行 `runtime\setup-rl.ps1`；脚本完成后把打印的解释器路径填入软件。

短训练完成不等于策略已经稳定；请使用独立验证报告判断结果。手动辅助体验不进入算法成绩比较。SHA256 是一致性校验，本构建流程未配置发布者数字签名。

维护者发布前应补入本次产物的实际验证记录和 SHA256SUMS；构建、干净机器安装、覆盖升级及远端下载应分别报告。此文件是本地发布说明草稿，不代表版本已公开发布。
