# ControlLab 0.2.1 更新说明（发布候选草稿）

日期：2026-10-08。本文描述当前源码的课程补全，**不表示 0.2.1 安装包已构建或已正式发布**。本轮分项验收和待完成的发布检查见 [0.2.1 验证记录](VALIDATION_0.2.1.md)。0.2.0 的安装器、CI 与升级证据保留在 [0.2.0 验证记录](VALIDATION_0.2.0.md)，不能代替新版检查。

## 学生可以逐步操作、保存和回看课程

- 预测、解释、草稿按课程和步骤保存；修改有修订记录，切课、返回或重启后可继续。课程步骤可直接回看，“为什么”可展开；课件要求变化会识别受影响的完成项，保留原记录和模板。
- L03/L04/L15 增加由真实物理模型生成的预置片段、读数揭示、预测卡及角度单位换算；曲线、角度、角速度和参数按步骤逐渐出现。
- L05/L10 可运行恰好 10 个物理步后暂停，默认步长下为 0.2 秒，便于公平比较正、负和零推力。
- L07/L08/L10/L12 可对本课给定的位置、速度或角度单独试算并查看执行分支；试算使用独立控制进程，不推进当前小车或改变当前控制器记忆。
- 编辑器增加行号、错误行定位、中文错误解释及原始回溯；载入课程模板前保留草稿并可查看差异。正在运行的源码快照与编辑中的草稿分别保存。

## 传统控制实验有可复现的对照结果

- L14 增加 P 参数扫描，保留每个候选的实际轨迹、指标和 CSV；主实验与另一个公布初态分别记录。
- L16 明确区分“杆未倒”和“已经回中”：公开判据为位置绝对值不超过 0.1 m、速度绝对值不超过 0.1 m/s，持续至少 1 秒。界面显示首次达标时间和当前连续时长，记录使用真实状态。
- L17 增加当前误差与有符号积分面积；控制器主动报告的积分、分量和冻结状态单独显示，面积动画不冒充代码内部变量。
- L18 可在同一单车速度场景比较无保护、积分限幅、条件积分三种方法，显示目标切换、真实饱和/冻结区间和有明确持续窗口的恢复时间；未恢复明确记录为空。
- L21 正式评价可打开每个成功、失败或错误回合，查看详细指标、协议、代码快照及轨迹。两个同条件报告可按相同用例、相同时间并排查看；提前结束的一方不会被补造后续数据。PPO 报告使用同一阅读器。
- L22 可以显式选择至少三种不同方法的练习/验证报告，导出包含 README、源码、参数、协议、全部轨迹和文件哈希的项目 ZIP。不同协议或不完整报告不会拼成一份完整成绩。

## 评价、记录和命令行更可靠

- 正式评价中的学生代码在独立进程执行，初始化、重置、控制及诊断调用均受超时限制；每例错误和已完成结果保留。取消后报告明确标记不完整，不能进入完整成绩比较。
- 健康回合复用同一个学生模块，每回合仅重置一次；出错的控制进程可以在后续回合重建。Windows 下强制终止评价父进程也会清理其学生子进程。
- `run-recording` 可读取 GUI 保存的相同实验配置、源码和力/速度输入模式重新计算，保存逐值差异及新记录。鼠标或混合操纵没有完整原始输入时只支持历史回放，不假称能由源码复算。
- 实验记录增加软件版本、配置哈希、速度帮助参数与主动上报的控制分量；缺失诊断仍显示未提供。

新增命令示例（工程虚拟环境已激活，输出目录须为新目录）：

```powershell
control-lab run-recording "学生目录/runs/原实验" --output-dir "学生目录/runs/复算"
control-lab sweep --kind p --condition primary --output-dir "学生目录/scans/p"
control-lab sweep --kind pi --output-dir "学生目录/scans/pi"
control-lab evaluate --controller student --controller-file my_controller.py --split validation --execution-timeout 0.5 --output-dir "学生目录/evaluations/validation"
```

## 强化学习课程补齐操作与证据

- L24 可用同一真实轨迹拆分、重计不同奖励，并保存版本化奖励 JSON。离线分析与训练环境采用相同公式；修改奖励后开启新训练，不能静默修改已有续训任务。
- L25/L26 增加真实动作映射、终止与时限示例、256 步烟测及零训练基线；多个 seed 的课程步骤要求实际运行结果，失败或取消不算完成。
- 训练任务可在关闭界面时选择停止并保存、继续后台运行或取消关闭。重开软件可恢复监控和停止任务；使用任务身份与进程创建时间识别进程，不按裸 PID 杀进程。
- 模型目录显示实际模型身份、奖励、训练步数和续训来源，并关联对应验证报告。L28 可以选择验证报告冻结模型后执行保留集，拒绝不完整或不匹配的验证出处。
- L29 增加固定 PD/PPO 的公平鲁棒性对照：同 5 个练习初态、7 个单独因素、2 种方法，共 70 回合。保留实际配置和失败结果，使用独立实验协议，不混入标准平衡成绩。

## TITA 学习接口

- 外部 Isaac/TITA 运行时可生成实际观测和动作接口表，记录关节顺序、单位、缩放、偏置、历史长度及源码版本。基础教学进程不导入 Isaac；CartPole 的四维状态和单个力动作不能直接套给 TITA。
- L32 增加模拟命令门实验与轨迹证据，包含限幅、失联超时、停止、急停锁存与明确重新启用。它验证教学模拟规则，不控制机器人，也不构成实机安全认证。
- 本轮 TITA 实测范围和仍未完成的可视/实机验收，以验证记录的具体证据为准。

## 本版本尚不承诺的结果

L29 的选修域随机化训练尚未实现。真人试讲、教学效果、干净 Windows 兼容性、公开 Release 到应用内安装完成的更新全链路、安装中断恢复及代码签名仍需独立完成。短 PPO 训练成功只证明训练与模型流程可运行，不等于学会平衡；已有旧版长期训练结果不作为本轮新增训练。

本轮没有改变“基础教学环境与 RL/Isaac 独立环境分开”的安装方式。已有安装和升级能力与 **0.2.1 新产物的完整验收、发布状态** 分开记录。
