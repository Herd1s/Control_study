# ControlLab 0.1.0 历史验证记录

本文仅保存 0.1.0 的测试证据与当时范围。版本验证分别见 [0.2.0](VALIDATION_0.2.0.md) 与 [0.2.1](VALIDATION_0.2.1.md)，本轮变更见 [0.2.1 发布说明](RELEASE_NOTES_0.2.1.md)。

验证日期：2026-10-07。环境：Windows x64、Python 3.13.5、项目独立 `.venv`。

## 已完成

- `python -m pytest -q`：20 项测试通过，另有 2 个子测试通过；扶正修复后复测耗时 10.35 秒。
- 覆盖连续推力动力学、输入限幅、文件不覆盖、实验记录、参考控制器、真实 Qt 鼠标拖动、惯性、暂停与重置、课程切换、两种代码输出、语法错误及死循环超时处理。
- `python -m pip check`：无依赖冲突。
- 三个课堂界面已生成截图并检查；第一课初始暂停，操作小车后开始。
- 扶正修复：拖动后点击重新扶正，物理与绘图状态均恢复为 `[0, 0, 0, 0]`，暂停等待操作；无输入时不再因随机初值自行倾倒。画布左上角英文装饰文字已删除。
- 界面精简：删除课程眉题、副标题、进度小字、侧栏装饰文案与版本号，以及画布周围的重复提示。第一课操作引导集中到右侧；保存及载入文件仍显示结果。6 项 GUI 交互测试及 2 个子测试通过，耗时 4.90 秒。
- `gui --code-file examples/first_action.py` 能将 VS Code 练习加载到第三课。
- Windows 便携版构建成功：`dist/ControlLab/ControlLab.exe` 和 `ControlLabCLI.exe`，二者共用 `_internal`。
- 在工程外目录启动冻结程序的 `doctor`，全部依赖检查及物理 reset/step 通过；依赖从打包目录加载。
- 冻结 CLI 与无控制台 GUI 分别通过课堂代码执行检查：真正启动子进程执行学生函数、返回 1.25 N 并推进物理状态。GUI 检查同时移除了进程的 Python 环境变量和 PATH 中的外部 Python 路径，退出码为 0。
- 冻结 CLI 参考控制器连续 3 回合各完成 500 步；最大位置偏移约为 0.117、0.128、0.046 m。
- 冻结程序能够创建学生工作区、读取外部控制器并保存实验记录。零推力模板在第 31 步倒下，符合该未完成练习的预期。

## 0.1.0 当时的范围

前三课为已实现功能。完整 PID 图形课程、强化学习训练、学习进度管理和机器人连接尚未实现。

本次验证在当前开发电脑进行，尚未在一台完全未安装 Python 的新电脑上验收。便携版包含 Python 运行时，分发时需要整个文件夹。安装向导只有 Inno Setup 模板，尚未生成或测试 `Setup.exe`。
