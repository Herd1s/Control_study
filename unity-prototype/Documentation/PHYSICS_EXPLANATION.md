# 第一课怎样联系高中物理

第一课先让学生自由拖动。点击“为什么会倒？”后，可以任选“动量与惯性”“重力与力矩”“怎样接住”，边观察边操作；切换主题不会重置或暂停实验。

## 从惯性讲到动量

从杆竖直、整体静止开始，让小车向右加速：支点向右运动，杆会先相对向左倾。可以联系公交车突然向前启动时，乘客相对车厢后仰的经验。惯性是物体保持原有运动状态的性质，不是一股额外的“向后推力”。

用高中动量知识补充原因：`p = mv`，合外力的冲量等于动量的变化；合外力恒定时写作 `Δp = F合 Δt`。改变速度需要力作用一段时间。软件里的蓝色箭头表示**小车动量的方向**，静止时隐藏；它不是推力箭头，也不是杆的倾倒方向。箭头用于方向示意，不应根据其长度读取精确动量数值。

拖动小车时有外部驱动力，不能把车和杆直接当作一个动量守恒的孤立系统。讨论杆的线动量时，`v` 应取杆的质心速度，也不能把转动简化为整根杆所有点具有相同速度。

## 为什么稍微倾斜就容易倒

先回忆杠杆：同样大小的力，作用线离支点越远，转动作用越明显。杆竖直时，重力作用线通过支点，重力关于支点的力矩为零；杆稍微偏斜后，重力的力臂出现，其力矩倾向于让偏斜扩大。

软件的橙色点位于杆的质心，橙色箭头竖直向下，表示重力。即使杆倾斜，重力方向仍然向下。

可按需介绍 `重力矩大小 = mgd = mgℓ|sinθ|`，其中 `d` 是支点到重力作用线的水平距离，`ℓ` 是支点到质心的距离。这个式子仅描述**重力产生的力矩**；小车带着支点加速时，杆的运动还受支点加速度影响，不能直接套用固定支点的转动方程来解释所有情况。

理想模型在完全竖直、静止且没有扰动时，可以一直停在那里。因此“再试一次”后不会凭空自动倒下；拖动、轻推等扰动才会让系统离开这一不稳定平衡。

## 为什么移动车能接住杆

可以先试一个局部经验：杆刚向右倾时，适当向右加速小车，可能把支点接到杆的下方，减缓倾倒。随后还要看杆已经转得多快，及时减速或反向。

这不是“向哪边倒就永远向哪边推”的通用规则。仅看倾角，可能来不及刹住；只追杆，也可能把车推到轨道边缘。后续课程由此引入四个可观察量：小车位置、速度，杆的倾角、角速度，再进入反馈与 PID。

## 课堂里的三个自由实验

1. 回中后先不动，再轻推，比较理想平衡和受扰动后的变化。
2. 从竖直静止开始向右拖，松手，观察杆的倾斜和小车动量箭头；不要把松手理解为速度立即归零。
3. 打开重力主题，观察偏斜时重力作用线与支点的位置关系；再试着接住杆，留意什么时候需要减速或反向。

这些实验均为可选观察，没有过关条件。第一课的目标是形成直觉，不要求记住全部公式或推导完整动力学。
